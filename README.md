# ALI VIDEO MAKER

A starter Streamlit app that creates a narrated scene-card video from a script.

## Deploy
1. Upload these files to a GitHub repository.
2. Deploy the repository using a Streamlit-compatible hosting provider.
3. Run `app.py`.

## Notes
- This starter produces a narrated slideshow with generated text scene cards, not AI-generated footage/images.
- gTTS requires internet access and availability may vary.
- Persian/Dari voice support is approximate; gTTS `fa` may not work in every environment.
- FFmpeg is installed through `packages.txt` on compatible hosts.
